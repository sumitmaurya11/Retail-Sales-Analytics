# Retail Sales Analytics Dashboard

## Project Overview
This project analyzes retail sales data using SQL and Tableau.

## Tools Used
- SQL (MySQL)
- Tableau Public
- Excel/CSV

## Key Insights
- Technology generated the highest revenue.
- West region achieved the highest sales.
- Sales increased steadily from 2014–2017.
- Top customers contributed significantly to revenue.

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Total Customers KPI
- Revenue by Category
- Sales Over Time
- Top Customers Analysis
- Regional Analysis
- Monthly Profit Trend
